# CHRONOS Specimen Structure Standard

**Status:** Archived — retained as the historical structure reference for SPEC-001 to SPEC-004  
**Archive scope:** SPEC-001 through SPEC-004 only

---

## 1. Purpose

This document records the structure used to organise CHRONOS evaluation specimens. It is retained to help readers interpret the four published specimens and their evidence records.

## 2. Archive closure

The CHRONOS specimen archive is closed at SPEC-001, SPEC-002, SPEC-003 and SPEC-004. No additional specimens are authorised or planned for this archive. This document is not an invitation or submission standard for new specimens.

## 3. Historical structure

The published specimens use specimen-specific structures. SPEC-001 to SPEC-003 use a layered evidence and reporting approach; SPEC-004 uses its documented numbered-folder structure. Readers should follow the actual directory and evidence references within each specimen rather than assume that every specimen has an identical directory layout.

## 4. Evidence traceability principle

Where the specimen records support it, analysis and conclusions should be traceable to extracted facts, and extracted facts should be traceable to preserved source evidence. Any limitation or missing link must be treated as a limitation, not silently filled by assumption.

## 5. Version and status

This document is an archival reference for the four completed specimens. It does not impose a retroactive requirement to restructure the published records.
